  PANDUAN PENGGUNAAN & DOKUMENTASI SISTEM INFORMASI GEOGRAFIS (SIG)
  PEMETAAN DAN REKOMENDASI DESTINASI WISATA POTENSIAL (TOPSIS)
================================================================================

Aplikasi "SiPeta-Wisata" adalah sebuah platform Sistem Informasi Geografis (SIG)
dan Sistem Pendukung Keputusan (SPK) yang dirancang khusus untuk memetakan sebaran
destinasi wisata serta menganalisis dan merekomendasikan lokasi wisata yang paling
potensial untuk dikembangkan atau dijadikan tempat investasi. 

Sistem ini menggabungkan visualisasi peta interaktif dengan perhitungan matematis
Metode TOPSIS (Technique for Order of Preference by Similarity to Ideal Solution)
secara real-time.

================================================================================
1. PENDAHULUAN & ARSITEKTUR SISTEM
================================================================================
SiPeta-Wisata dirancang untuk mengatasi permasalahan dalam penentuan prioritas
pengembangan destinasi wisata daerah. Dengan adanya sistem ini:
* Dinas Pariwisata (Kepala) dapat memantau destinasi potensial secara cepat 
  dan mengambil kebijakan pariwisata berbasis data nyata.
* Investor dapat mengidentifikasi lokasi investasi strategis berdasarkan aspek
  aksesibilitas, fasilitas penunjang, keamanan, dan geografis.
* Administrator memiliki kontrol penuh untuk memodifikasi parameter analisis
  (kriteria & bobot) secara dinamis sesuai kebutuhan daerah.

Sistem menggunakan arsitektur modern Single Page Application (SPA) melalui
kombinasi Laravel (sebagai API & Backend) dan Vue 3 (sebagai Frontend), yang 
dijembatani secara seamless menggunakan Inertia.js.


================================================================================
2. TEKNOLOGI YANG DIGUNAKAN (TECH STACK)
================================================================================
* Backend (Core): Laravel 12 (versi terbaru dengan performa maksimal)
* Frontend Framework: Vue 3 (Composition API dengan TypeScript)

5. ALUR METODE TOPSIS PADA APLIKASI
================================================================================
Proses perhitungan TOPSIS berjalan otomatis di dalam `HasilTopsisController.php`
melalui langkah-langkah sistematis berikut:

1. PEMBENTUKAN MATRIKS KEPUTUSAN (X):
   Sistem menarik seluruh nilai subkriteria dari setiap lokasi wisata (alternatif)
   terhadap 5 kriteria yang telah ditetapkan.

2. NORMALISASI MATRIKS (R):
   Setiap elemen matriks keputusan dinormalisasi dengan membaginya dengan akar kuadrat
   dari jumlah kuadrat seluruh nilai kriteria tersebut:
   Formula: R_ij = X_ij / sqrt( sum( X_ij^2 ) )

3. PEMBOBOTAN MATRIKS TERAKTUALISASI (V):
   Mengalikan matriks normalisasi (R) dengan bobot kriteria masing-masing (W):
   Formula: V_ij = W_j * R_ij

4. PENENTUAN SOLUSI IDEAL POSITIF (A+) & SOLUSI IDEAL NEGATIF (A-):
   * A+ mengambil nilai maksimal untuk kriteria Benefit dan minimal untuk kriteria Cost.
   * A- mengambil nilai minimal untuk kriteria Benefit dan maksimal untuk kriteria Cost.

5. PERHITUNGAN JARAK SOLUSI IDEAL (D+ & D-):
   * D+ (Jarak ke Solusi Ideal Positif):
     Formula: D_i+ = sqrt( sum( (V_ij - A_j+)^2 ) )
   * D- (Jarak ke Solusi Ideal Negatif):
     Formula: D_i- = sqrt( sum( (V_ij - A_j-)^2 ) )

6. PERHITUNGAN PREFERENSI (V_i) & PERANGKINGAN:
   Nilai preferensi dihitung untuk setiap alternatif. Nilai ini berkisar antara 0 - 1.
   Formula: V_i = D_i- / (D_i+ + D_i-)
   Semakin mendekati angka 1, semakin potensial alternatif lokasi wisata tersebut.
   Sistem mengurutkan nilai V_i dari yang terbesar hingga terkecil untuk 
   menghasilkan peringkat (Ranking).

6. PANDUAN INSTALASI & DEPLOYMENT LOKAL
================================================================================
Ikuti langkah-langkah di bawah ini untuk menjalankan aplikasi di komputer lokal:

PRASYARAT (PREREQUISITES):
* PHP >= 8.2 (Sangat disarankan menggunakan PHP 8.3)
* Composer (Dependency Manager untuk PHP)
* Node.js >= 18 & NPM (Untuk compile modul frontend & Tailwind v4)
* Web Server & Database: Laragon (Direkomendasikan), XAMPP, atau Laravel Sail.

LANGKAH INSTALASI:

Langkah 1: Ekstrak atau Buka Folder Project
Pastikan folder d:/laragon/www/SiPeta-Wisata telah siap.

Langkah 2: Konfigurasi Environment File
1. Salin `.env.example` menjadi `.env`
2. Buka `.env` dan atur koneksi database Anda:
   -------------------------------------------------
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=sipeta
   DB_USERNAME=root
   DB_PASSWORD=
   -------------------------------------------------

Langkah 3: Install Dependensi PHP (Laravel)
Buka terminal (PowerShell / Command Prompt) di direktori project, lalu jalankan:
> composer install

Langkah 4: Jalankan Migrasi & Import Database Default
1. Buat database baru bernama `sipeta` di phpMyAdmin atau DBMS Anda.
2. Anda dapat mengimpor database contoh siap pakai yang sudah dilengkapi 28 destinasi
   wisata serta nilai kriteria lengkap dari file SQL yang tersedia:
   * Lokasi File: `database/sipeta.sql`
   * Import menggunakan phpMyAdmin, Laragon Database Tool, atau Terminal:
     > mysql -u root -p sipeta < database/sipeta.sql
3. Jika ingin memulai database kosong, jalankan migrasi Laravel:
     > php artisan migrate --seed

Langkah 5: Install Dependensi Javascript (Vue, PrimeVue, Leaflet)
Jalankan perintah berikut di terminal:
> npm install

Langkah 6: Generate Application Key
> php artisan key:generate

Langkah 7: Menjalankan Server Pengembangan (Localhost)
Untuk mempermudah, jalankan perintah development terintegrasi (concurrently):
> composer dev
Perintah di atas akan secara otomatis menjalankan 3 layanan sekaligus:
1. Laravel Development Server (`php artisan serve`) di http://127.0.0.1:8000
2. Queue Listener (`php artisan queue:listen`)
3. Vite Frontend Server (`npm run dev`) untuk hot-reloading Vue 3 & Tailwind v4.

Jika Anda ingin menjalankannya secara terpisah di terminal yang berbeda:
* Terminal 1 (Backend): php artisan serve
* Terminal 2 (Frontend): npm run dev

7. PANDUAN PENGGUNAAN SISTEM (MANUAL PENGGUNA)
================================================================================

--------------------------------------------------------------------------------
[A] HALAMAN UTAMA & LOGIN
--------------------------------------------------------------------------------
1. Akses http://127.0.0.1:8000 di peramban (browser) Anda.
2. Klik tombol "Login" di pojok kanan atas.
3. Masukkan Email dan Password akun Anda (sesuai peran Anda).
4. Klik "Login" untuk masuk ke dashboard utama.

--------------------------------------------------------------------------------
[B] BAGI ADMINISTRATOR (MANAJEMEN & KALKULASI)
--------------------------------------------------------------------------------

Langkah 1: Mengelola Jenis Wisata
* Masuk ke menu "Jenis Wisata" di panel admin.
* Gunakan tombol "Tambah" untuk membuat jenis baru (misal: Wisata Kuliner).
* Data ini akan otomatis menjadi opsi pilihan saat menambahkan Lokasi Wisata.

Langkah 2: Mengelola Kriteria & Subkriteria (PENTING!)
* Buka menu "Kriteria". Pastikan total bobot dari seluruh kriteria adalah 100%.
  Jika total bobot TIDAK 100%, sistem secara otomatis akan memblokir proses TOPSIS
  dan meminta Anda memperbaikinya terlebih dahulu demi keabsahan matematis.
* Masuk ke menu "Subkriteria" untuk memberikan rincian bobot (1-5) pada tiap kriteria.
  Subkriteria bertindak sebagai instrumen penilaian parameter objek wisata.

Langkah 3: Menginput Lokasi Wisata (GIS & Pemetaan)
* Masuk ke menu "Lokasi Wisata", lalu klik "Tambah Data".
* Masukkan Nama Lokasi Wisata.
* Pilih Jenis Wisata.
* Masukkan koordinat geografis yang tepat (Latitude dan Longitude). 
  (Tips: Koordinat bisa didapatkan dari Google Maps).
* Tentukan nilai aspek Lokasi dengan memilih opsi Subkriteria yang tersedia 
  (Fasilitas, Keamanan, Transportasi, Akses Lokasi).
* Klik "Simpan". Sistem secara otomatis akan mencatat nilai alternatif tersebut.

Langkah 4: Fitur Kolom Dinamis (Dynamic Custom Column)
* SiPeta-Wisata dilengkapi dengan fitur super premium untuk menambah kolom kriteria baru.
* Pada tabel Lokasi Wisata, klik "Tambah Kolom".
* Ketikkan nama kolom baru yang diinginkan, sistem secara otomatis akan melakukan
  generasi skema tabel database (`Schema::table`) di backend secara real-time.
* Kolom baru tersebut akan langsung tersedia di formulir input lokasi wisata!

Langkah 5: Perhitungan TOPSIS & Peringkat Potensi
* Klik menu "Hasil TOPSIS".
* Sistem akan memproses seluruh perhitungan TOPSIS (Matriks Awal -> Normalisasi ->
  Matriks Terbobot -> Solusi Ideal -> Jarak Ideal -> Preferensi -> Perangkingan).
* Hasilnya akan disajikan secara visual dalam tab-tab terstruktur dan premium.
* Buka menu "Pemetaan" untuk melihat visualisasi GIS lokasi wisata dengan penanda (marker)
  warna pada Leaflet Map sesuai hasil perangkingan TOPSIS-nya.

8. FITUR SPESIAL & TROUBLESHOOTING
================================================================================

--------------------------------------------------------------------------------
MASALAH: Error "Total bobot harus 100, sekarang: X" saat membuka Hasil TOPSIS
--------------------------------------------------------------------------------
* Penyebab: Jumlah persentase bobot dari seluruh kriteria di database tidak bernilai 100%.
* Solusi  : Buka menu Kriteria sebagai Administrator. Edit bobot masing-masing kriteria
            sehingga apabila dijumlahkan nilainya pas 100%. Setelah itu, buka kembali 
            Hasil TOPSIS untuk memulai kalkulasi otomatis.

--------------------------------------------------------------------------------
MASALAH: Peta Leaflet tidak memuat peta dasar (Basemap) / Abu-abu saja
--------------------------------------------------------------------------------
* Penyebab: Komputer tidak terhubung ke internet, sehingga gagal memuat tile map Leaflet.
* Solusi  : Pastikan koneksi internet stabil saat menjalankan aplikasi agar peta satelit
            dan jalan dari OpenStreetMap dapat dimuat dengan lancar.

--------------------------------------------------------------------------------
MASALAH: Penanda (Marker) Peta tidak muncul
--------------------------------------------------------------------------------
* Penyebab: Lokasi wisata belum diset nilai koordinat Latitude & Longitude-nya atau
            perhitungan TOPSIS belum dijalankan (tabel `hasil_topsis` kosong).
* Solusi  : 
  1. Pastikan setiap lokasi wisata memiliki koordinat latitude (nilai negatif di Indonesia,
     misal -2.xxxx) dan longitude (misal 140.xxxx).
  2. Buka menu Hasil TOPSIS sebagai admin terlebih dahulu untuk memicu kalkulasi
     dan mengisi tabel hasil perangkingan pariwisata.
